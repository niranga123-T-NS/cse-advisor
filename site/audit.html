Data checks

What is checked

Each figure read from a company report keeps the exact PDF line it came from. A figure only counts towards a score or a label if a cross-check confirms it (✓ verified). Figures that fail a check are shown with ⚠ and left out.

  1. Last year's column = last year's report. Each report prints the same period last year next to the current figures. When that matches last year's own report, the row and columns were read correctly. This match is also used to pick the right columns when a row holds several.
  2. Printed % change. Where a % change column is printed, it must agree with the current and prior figures.
  3. Quarter vs year-to-date by arithmetic. Year-to-date = the previous report's year-to-date + this quarter. The year-end figure must equal the annual report's EPS.
  4. EPS = attributable profit ÷ shares in issue (latest four reports).
  5. EPS growth agrees with profit growth.
  6. Net assets per share: the balance sheet's comparative column must equal the figure at the last year-end.
  7. Plausibility. Per-share figures are checked against the share price. Full-year EPS more than 13 months old is never used. US-dollar rows are skipped. Long-term EPS growth is only measured across years whose figures link up, so share splits don't distort it.
